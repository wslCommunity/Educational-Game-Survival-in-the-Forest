# Red VPN — рекламный ролик

Готовое видео со звуком для Telegram / Reels / Stories.

## Файлы

- `output/RedVPN_ad_9x16.mp4` — вертикальный ролик 1080×1920 (~19 с)
- `output/RedVPN_ad_16x9.mp4` — горизонтальный 1920×1080
- `ad.html` — исходная анимация
- `assets/logo.png` — логотип
- `record.mjs` — скрипт записи

1. Логотип Red VPN
